# ComicTranslate（한국어）

**Firefox**와 **Chrome**을 위한 브라우저 확장 프로그램입니다. 페이지의 이미지, 만화, 웹툰에 있는 글자를 찾아 OCR로 읽고 번역한 뒤 원래 글자를 지우고 번역문을 같은 말풍선과 그림자에 다시 그립니다.

## 기능

1. **탐지** — 페이지의 콘텐츠 이미지를 찾고 아이콘과 썸네일은 기본적으로 건너뜁니다.
2. **읽기** — OCR로 글자, 위치, 언어를 인식합니다.
3. **번역** — 읽은 글자를 선택한 언어로 번역합니다.
4. **다시 그리기** — 원래 글자를 지우고 번역문을 말풍선과 그림자 안에 배치합니다.
5. **교체** — 번역된 이미지를 페이지에 표시합니다. 이미지가 전송되는 대상은 사용자가 선택한 번역 엔진뿐입니다.

번역 결과는 캐시되므로 같은 페이지를 다시 읽어도 다시 과금되지 않습니다.

## 설치

### Firefox

1. `about:debugging#/runtime/this-firefox`를 엽니다
2. **Load Temporary Add-on…**을 선택합니다
3. 프로젝트 루트의 `manifest.json`을 선택합니다
4. 번역할 페이지를 새로고침합니다

### Chrome

```bash
python3 tools/build.py
```

1. `chrome://extensions`를 엽니다
2. 오른쪽 위의 **Developer mode**를 켭니다
3. **Load unpacked**를 선택합니다
4. 프로젝트 루트가 아니라 `dist/chrome`을 선택합니다
5. 확장 프로그램과 페이지를 새로고침합니다

## 인터페이스 언어

**설정 → 언어 → 인터페이스 언어**에서 English、简体中文、繁體中文、日本語、한국어 중 하나를 선택하세요. **브라우저와 일치**를 선택하면 브라우저 언어를 사용합니다.

## 번역 엔진

| 엔진 | 설명 |
|---|---|
| **Google Lens(무료)** | 익명 OCR와 번역이며 계정이 필요 없습니다. |
| **Lens OCR + 내 로컬 AI** | Lens가 글자를 읽고 추출한 문자열만 사용자의 로컬 서버로 보냅니다. |
| **Lens + Lara 텍스트** | 실제 전송한 문자 수로 과금되며 Lara 자격 증명이 필요합니다. |
| **Lara 이미지(공식)** | Lara가 전체 번역 이미지를 생성하며 이미지당 10,000문자입니다. |
| **Lens OCR + Microsoft Translator** | 무료 할당량: 월 2,000,000자(약 1,300페이지). Microsoft 계정 무료 등급이 필요합니다. |

무료 할당량으로 몇 페이지를 번역할 수 있나요?

- **Google Lens: 무제한.** 무료 익명이며 계정, 할당량, 청구가 없습니다. 기본 엔진입니다.
- **Lens OCR + Microsoft Translator: 월 약 1,300페이지.** 무료(F0) 등급은 **월 2,000,000자**이며 매월 갱신됩니다. 다 쓰면 다음 달까지 중단되며, 유료 등급으로 올리지 않는 한 청구되지 않습니다.
- **Lens OCR + 내 로컬 AI: 무제한.**

### Microsoft Translator 키 발급받기(무료 F0 등급)

`lens-azure` 엔진은 무료 익명 Lens OCR와 Microsoft 공식 Translator API를 함께 사용합니다. 무료(F0) 등급은 **월 2,000,000자(만화 약 1,300페이지)**이며 매월 갱신되고, 다 쓰면 중단될 뿐입니다. 리소스를 유료 등급으로 올리지 않는 한 청구되지 않습니다.

1. [Azure Portal](https://portal.azure.com/)을 열고 로그인합니다(새 계정은 Azure 구독이 필요하며 무료 계정으로 충분합니다).
2. **리소스 만들기** → **Translator** 검색 → **만들기**. **Azure AI services** 멀티서비스 리소스로 만들어도 되며 둘 다 사용 가능합니다.
3. 구독, 리소스 그룹, **지역(Region)**을 선택합니다. 가까운 지역이면 됩니다(예: `japaneast`, `westus2`). 정확한 값을 메모하세요. 확장 프로그램에 그대로 입력해야 합니다.
4. **가격 책정 계층(Pricing tier)**에서 **Free F0**(월 200만 자)를 선택합니다. 만들기를 마치고 배포가 끝날 때까지 기다립니다.
5. 리소스를 열고 → **키 및 엔드포인트(Keys and Endpoint)**(왼쪽 *리소스 관리* 아래)를 엽니다. **KEY 1**(두 키 모두 가능)과 **위치/지역(Location/Region)**을 복사합니다.
   - Translator 단일 서비스 리소스: 표시된 **Location**을 사용합니다(예: `japaneast`).
   - 멀티서비스(Azure AI services) 리소스: **`global`**을 사용합니다.
6. 이 확장 프로그램에서: 설정 → 엔진 → **Lens OCR + Microsoft Translator**를 선택하고 키와 지역을 붙여넣은 뒤 **Microsoft 키 테스트**를 누릅니다. 테스트는 1글자만 번역합니다(`'a'` → `'es'`). 월 무료 할당량에서 1자만 소모됩니다.
7. 이후에는 평소대로 번역하면 됩니다. 브라우저를 떠나는 것은 OCR로 읽은 문자열뿐입니다. 이미지는 OCR를 위해 Google로만 전송되며 Microsoft로는 전송되지 않습니다.

테스트에서 **401**이 나오면 키와 지역이 서로 다른 리소스에서 왔거나 지역 철자가 틀린 것입니다. 같은 **키 및 엔드포인트** 페이지에서 둘 다 다시 복사하세요. 무료 할당량을 다 쓰면 할당량 메시지와 함께 중단되며 다음 달에 복원됩니다.

## 개인정보 보호

무료 Lens와 로컬 AI는 OCR을 위해 이미지를 Google에 전송합니다. 로컬 AI 엔진은 원본 이미지가 아니라 OCR로 읽은 문자열만 전송합니다. 요청에는 쿠키나 계정 정보가 포함되지 않습니다. Lara 요청에는 `X-No-Trace`가 포함됩니다.

## 로컬 AI

설정에서 **Lens OCR + your own local AI**를 선택하고 서버 URL을 입력한 뒤 **로컬 서버 테스트**를 누르세요. LM Studio, Ollama, vLLM, llama.cpp의 OpenAI 호환 Chat 경로를 지원합니다. 서버는 입력과 같은 순서의 JSON 번역 배열을 반환해야 합니다.
