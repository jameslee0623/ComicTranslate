# ComicTranslate（日本語）

**Firefox** と **Chrome** 向けのブラウザ拡張機能です。ページ内の画像・漫画・ウェブトゥーンの文字を検出し、OCR で読み取り、翻訳して元の文字を消し、吹き出しや枠の中に翻訳文を描画します。

## 機能

1. **検出** — ページ内のコンテンツ画像を検出し、アイコンやサムネイルをデフォルトで除外します。
2. **読み取り** — OCR で文字、位置、言語を取得します。
3. **翻訳** — 読み取った文字を指定した言語に翻訳します。
4. **再描画** — 元の文字を消し、吹き出しや枠のレイアウトに合わせて翻訳文を描画します。
5. **置換** — 翻訳済みの画像をページに表示します。画像が送信されるのは、選択した翻訳エンジンだけです。

翻訳結果はキャッシュされるため、同じページをもう一度読んでも再課金されません。

## インストール

### Firefox

1. `about:debugging#/runtime/this-firefox` を開きます
2. **Load Temporary Add-on…** を選びます
3. プロジェクト直下の `manifest.json` を選びます
4. 翻訳したいページを再読み込みします

### Chrome

```bash
python3 tools/build.py
```

1. `chrome://extensions` を開きます
2. 右上の **Developer mode** を有効にします
3. **Load unpacked** を選びます
4. プロジェクトルートではなく `dist/chrome` を選びます
5. 拡張機能とページを再読み込みします

## 画面の言語

**設定 → 言語 → インターフェース言語** で English、简体中文、繁體中文、日本語、한국어 を選べます。**ブラウザーに合わせる** を選ぶと、ブラウザーの言語が使われます。

## 翻訳エンジン

| エンジン | 内容 |
|---|---|
| **Google Lens（無料）** | 匿名の OCR と翻訳。アカウントは不要です。 |
| **Lens OCR + ローカル AI** | Lens が文字を読み取り、抽出した文字列だけを自分のローカルサーバーへ送ります。 |
| **Lens + Lara テキスト** | 送信した文字数課金。Lara の資格情報が必要です。 |
| **Lara 画像（公式）** | Lara が翻訳画像全体を生成します。画像1枚につき10,000文字です。 |

## プライバシー

無料 Lens とローカル AI では、OCR のために画像が Google に送信されます。ローカル AI には抽出した文字列だけが送信され、元画像は送信されません。リクエストに Cookie やアカウント情報は含まれません。Lara のリクエストには `X-No-Trace` が付きます。

## ローカル AI

設定で **Lens OCR + your own local AI** を選び、サーバー URL を入力して **ローカルサーバーをテスト** を押します。LM Studio、Ollama、vLLM、llama.cpp の OpenAI 互換 Chat ルートに対応しています。サーバーには入力と同じ順序の JSON 翻訳配列を返してください。

## 検証

```bash
./tools/verify.sh
python3 tools/build.py
```
