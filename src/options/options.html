Engine

Lara meters usage in characters, two different ways. The full-image engine bills a FLAT 10,000 characters per image, so 40 pages is about 400,000 characters — enough to exhaust a Pro month (500,000) and far beyond the 10,000 chars/month of API access on the Free plan. The “Lens OCR + Lara text” engine bills only the characters actually sent — a manga page is usually 500–1,500 — so the same allowance covers roughly 10–20 pages. Cached pages are always free. All four image modes bill the same flat 10,000 per image, so the model is a quality/speed choice, not a cost one: only inpainting removes the original text, which is what makes a comic read cleanly. Requests are sent with X-No-Trace, so Lara neither stores nor trains on your images. Get credentials.

Google Lens finds the boxes and reads the text for free; only those strings are POSTed to your own server, which answers with the translations index-aligned with the input. The reply is drawn onto the page exactly like the free engine does it. A bare host:port is treated as an OpenAI-compatible chat server (/v1/chat/completions), which is what LM Studio, Ollama, vLLM and llama.cpp expose by default; give the full path for anything else. The page image never leaves the browser.

Using LM Studio with a reasoning model? Turn OFF Separate reasoning_content and content in API responses in its Developer Settings. With it on, a model can put its entire answer in the reasoning field and leave the answer itself empty, and there is then nothing to draw on the page. Reasoning models are also slow — a 12B model spent nearly two minutes on three short lines while testing — so a small instruct model gives a far better experience. Switching to another page cancels a translation that is still running, so the model stops immediately instead of finishing work for the page you just left.

Rendering

Limits

A low delay gets rate-limited by Google quickly. 1500 ms is a reasonable floor.

Privacy

Any image processed is uploaded to Google for OCR and translation — that is inherent to using this extension. Requests are anonymous: no cookies or account data are sent.

Lara usage

What the Lara engines bill this calendar month: text is counted by the characters actually sent; the full-image engine bills a flat 10,000 per image. Lara's own reset day is account-specific and unknowable here, so the counter follows the calendar month and a manual reset is provided. Free plan: 10,000 chars/month of API access; Pro: 500,000. One image costs 10,000, so the full-image engine empties the Free allowance in a single page.
